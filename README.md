🎮 Jokenpô em Python
Um jogo de Jokenpô (Pedra, Papel e Tesoura) desenvolvido em Python como meu primeiro projeto de programação.

📌 Sobre o projeto
O jogador escolhe entre Pedra, Papel ou Tesoura, enquanto o computador faz uma escolha aleatória.

O jogo compara as escolhas e informa o resultado de cada rodada, mantendo também um placar com:

🏆 Vitórias
💀 Derrotas
🤝 Empates
✨ Funcionalidades
🎮 Jogador contra computador
🎲 Escolha aleatória do computador
✅ Validação das opções escolhidas
🏆 Contador de vitórias
💀 Contador de derrotas
🤝 Contador de empates
🔄 Possibilidade de jogar várias rodadas
🛠️ Tecnologias utilizadas
🐍 Python 3
🎲 Biblioteca random
🎯 Regras
Jogada	Vence
🪨 Pedra	✂️ Tesoura
📄 Papel	🪨 Pedra
✂️ Tesoura	📄 Papel
Se os dois jogadores escolherem a mesma opção, a rodada termina em empate.

Variáveis
Condicionais (if, elif, else)
Loops
Entrada de dados com input()
Saída de dados com print()
Listas
Geração de valores aleatórios
Validação de entrada
